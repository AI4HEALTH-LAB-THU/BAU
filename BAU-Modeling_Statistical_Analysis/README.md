# Biological age uncertainty

Probabilistic age models for biological age gap (BAG) and biological age
uncertainty (BAU), with clinical and molecular association analyses.

Python 3.10.19 and R 4.6.0.

Set input and output paths in `settings.sh`, then run:

```bash
source settings.sh
python3.10 -m pip install -r requirements.txt
Rscript install_packages.R
bash run.sh all
```
